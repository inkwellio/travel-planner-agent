# 行程助手 · 联调清单

> 目标：在 mock 全通的基础上逐项接入真实服务。每项可单独开关：不填对应 key 即回退 mock，不影响其它项。
> 所有密钥只放仓库根目录 `.env`（已在 `.gitignore`），前端只拿 `VITE_AMAP_JS_KEY`。

## 0. 准备

```bash
npm install
cp .env.example .env
npm run dev          # server :8787 / web :5173
curl localhost:8787/api/health   # 看 llm / map / search / sample 当前是否为 mock
```

## 1. 环境变量总表

| 变量 | 用在 | 必填 | 申请入口 | 无值时 |
|---|---|---|---|---|
| `DEEPSEEK_API_KEY` | 后端：推荐、景点分配、摘要、网页字段提取、兜底生成 | 否 | https://platform.deepseek.com → API Keys | 本地规则 mock |
| `DEEPSEEK_BASE_URL` | 后端 | 否 | 默认 `https://api.deepseek.com` | — |
| `DEEPSEEK_MODEL` | 后端 | 否 | 默认 `deepseek-chat` | — |
| `AMAP_WEB_KEY` | 后端：POI、公交/驾车路径、周边停车、天气 | 否 | https://console.amap.com/dev/key/app → 创建应用 → 添加 Key，服务平台选 **Web服务** | MockProvider + 本地杭州示例库 |
| `VITE_AMAP_JS_KEY` | 前端：渲染地图 | 否 | 同上控制台，服务平台选 **Web端(JS API)**（与 Web 服务 key 分开） | 静态占位地图 |
| `AMAP_SECURITY_CODE` | 后端：`/_AMapService` 代理拼接 jscode | 配 JS key 时必填 | 创建 JS API key 时生成的「安全密钥」 | 代理返回 503，地图部分服务不可用 |
| `SEARCH_PROVIDER` | 后端：`bocha` 或 `tavily` | 否 | — | — |
| `SEARCH_API_KEY` | 后端：景点补充资料网页检索 | 否 | 博查 https://open.bochaai.com ；Tavily https://app.tavily.com | 不搜索，直接走模型生成（source=llm） |
| `DB_PATH` | 后端：SQLite（行程 checkpoint、资料库、分享快照） | 否 | 默认 `server/data/travel.db` | — |
| `PORT` | 后端端口 | 否 | 默认 8787 | — |
| `RATE_LIMIT_PER_MIN` | 后端：聊天/生成路线/编辑每 IP 每分钟上限 | 否 | — | dev 60，production 5；0=不限 |
| `PUBLIC_RATE_LIMIT_PER_MIN` | 后端：公开 API 和地图代理每 IP 每分钟上限 | 否 | — | dev 600，production 120；0=不限 |
| `DAILY_LIMIT_DEEPSEEK` / `DAILY_LIMIT_AMAP` / `DAILY_LIMIT_SEARCH` | 后端：每日全局外部调用上限，分别计数 | 否 | — | dev 不限，production 2000 / 5000 / 500；0=不限 |
| `TRUST_PROXY` | 后端：反向代理后识别真实 IP | 部署时 | — | `loopback` |

> 生产部署：`/api` 与 `/_AMapService` 需同域反向代理到后端；JS API 的安全密钥**不要**放前端。

## 2. 联调步骤与验收点

### 2.1 DeepSeek
1. 填 `DEEPSEEK_API_KEY`，重启；`/api/health` 中 `llm: "deepseek"`。
2. 聊天发送「带爸妈慢慢逛西湖」。
- [ ] 回复为自然语言，推荐 id 均来自候选池（不出现库外景点）
- [ ] 生成路线：骨架阶段每天景点不重复、不遗漏，数量与天数匹配（否则后端自动回退距离聚类）
- [ ] 每天摘要 ≤ 40 字；接口超时/报错时日志出现 `[deepseek] fallback to mock`，流程不中断
- [ ] 无订票/支付相关内容

### 2.2 高德 Web 服务（`AMAP_WEB_KEY`）
1. 填 key，重启；`map: "amap"`，`sample: false`。
2. 新建行程 → 发送消息。
- [ ] 推荐卡来自高德 POI（风景名胜 110000），显示高德照片与评分；无照片的保留色块
- [ ] 卡片不再出现「示例数据」标签，底部提示不再写「示例数据」
- [ ] 交通段：公共交通显示真实线路、换乘站、用时、票价；自驾显示用时、里程、过路费、附近停车场名称与距离；不再出现「示例估算·仅供参考」
- [ ] 天气提醒来自高德预报（不再标「示例天气」）；预报有雨的一天显示室内备选
- [ ] 断网或配额用尽时日志出现 `[map] fallback`，对应段回退估算并带「仅供参考」
- [ ] 前端 Network 中**没有**任何 `restapi.amap.com` 请求（Web 服务只走后端）

### 2.3 高德 JS API（`VITE_AMAP_JS_KEY` + `AMAP_SECURITY_CODE`）
1. 填两项，重启 dev（Vite 需重启才读新 env）。
- [ ] 右栏/分享页/导出页显示真实地图，标注 `D1-1…`，当前天路线为主题 primary 色
- [ ] 地图编号与时间线顺序一致；拖拽排序后地图随新版本更新
- [ ] Network 中瓦片/服务请求走 `/_AMapService/...`，URL 与前端源码中均**不含**安全密钥
- [ ] `curl localhost:8787/_AMapService/v3/ip` 返回高德 JSON（非 503）

### 2.4 网页搜索资料库（`SEARCH_PROVIDER` + `SEARCH_API_KEY`，需同时有 DeepSeek 与高德 key）
1. 填 key，重启；`search: "bocha"|"tavily"`。
2. 发送消息触发推荐（首次会对缺资料的 POI 搜索 + 提取，较慢）。
- [ ] 字段旁出现「来源：XX · M月D日更新」，点击打开原网页，内容能在原文中找到
- [ ] 搜不到依据的景点字段显示灰色「仅供参考」（source=llm）
- [ ] 再次推荐同一景点不再触发搜索（读库）；`sqlite3 server/data/travel.db "select poi_id,source,fetched_at from enrichment"` 可见记录
- [ ] 过期验证：把某条 `fetched_at` 改为 31 天前，再次推荐会重新检索
- [ ] 手动覆盖接口已移除，公开请求不能修改共享景点资料。

### 2.5 持久化 / 匿名用户 / 分享
- [ ] 生成路线后重启后端，刷新页面历史行程与各版本仍在
- [ ] 另一浏览器（或清 localStorage）看不到前者行程；直接请求他人 trip id 返回 404
- [ ] 分享链接 `/s/<21位ID>` 免登录可看；分享后继续修改，分享页内容不变（快照）
- [ ] 分享页「复制一份到我的行程」后，新行程出现在当前浏览器历史中，版本为 v1
- [ ] 导出 PDF：首页为概览，之后每天另起一页，含地图、时间线、两种交通方式，保留「来源」「仅供参考」标记

### 2.6 限流与每日额度
1. 本地验证：`RATE_LIMIT_PER_MIN=2 npm run dev`，连续发 3 条消息。
- [ ] 第 3 次返回 429 + `Retry-After`；聊天里出现「规划得有点快，稍等几秒再试」，输入框与发送按钮显示倒计时，到时自动恢复
- [ ] 同时查看历史行程、切换版本、打开分享页、导出 PDF 不受影响（只有聊天/生成/编辑限流）
2. 每日额度：`DAILY_LIMIT_DEEPSEEK=1`（需配 DeepSeek key），发两次消息。
- [ ] 第 2 次返回 429 `code=daily`，聊天提示「今天的规划次数已用完，明天再来」；生成路线中途耗尽时流式中止，未完成草稿被回收
- [ ] `GET /api/usage` 可看当日各外部服务计数与上限；计数存 SQLite 表 `daily_usage(date, provider, count)`，重启后端不清零，按台北日期分行（跨日自然归零）
- [ ] 每分钟限流为单进程内存实现；多实例部署需改为 Redis

### 2.7 前端交互
- [ ] 生成中：已出的天可看，无拖拽/删除按钮；完成后可拖拽（桌面鼠标、手机长按 200ms）
- [ ] 手机底部抽屉：手柄可跟手拖动，松手吸附到收起/半屏/全屏；轻点切换
- [ ] 左侧搜索可按标题、偏好、同行人、景点名过滤

## 4. 已知限制
- 匿名会话由服务端签发并验证，客户端需保护凭证；清除本机数据后无法自动找回，跨设备同步需另行接入登录。生产环境需使用 HTTPS。
- 导出 PDF 依赖浏览器打印（「另存为 PDF」）；脚本中用 Playwright `page.pdf` 验证分页。
- mock 天气固定第 2 天下雨，便于验证雨天备选。
